# Мониторинг конкурентов: финансовое сопровождение, аудит, тарифы

Персональный AI-анализатор рынка конкурентов для консультанта в нише **финансового сопровождения деятельности, финансового аудита и экспертизы / формирования тарифов** (тарифное регулирование, обоснование тарифов для ресурсоснабжающих организаций).

Приложение принимает текст, изображение или адрес сайта конкурента и возвращает структурированный JSON: сильные и слабые стороны, уникальные предложения, оценки по шкале 0–10 и рекомендации.

## Кейс

Консультант готовит тарифные заявки и сопровождает аудит. Чтобы выстраивать предложение, ему нужно регулярно понимать, как позиционируются конкуренты: какие услуги называют, насколько прозрачны цены, насколько глубоко показана тарифная экспертиза, вызывает ли сайт доверие. Вручную это часы чтения сайтов и отчётов. Приложение делает первичный разбор за минуту; выводы модели нужно проверять по первоисточнику.

## Что умеет

| Функция | Как работает |
|---|---|
| Анализ текста | `POST /analyze_text`: текст страницы услуг, предложения или отчёта конкурента |
| Анализ изображений | `POST /analyze_image`: скриншот лендинга, баннер, страница PDF-отчёта |
| Сбор данных с сайта | `POST /parse_demo`: настоящий Chrome через Selenium открывает страницу, берёт title, H1, первый содержательный абзац, заголовки разделов и скриншот, всё это разбирает модель |
| История | `GET /history`: последние 10 запросов в `history.json` |
| Список конкурентов | `GET /competitors`: из `backend/config.py` |
| Веб-интерфейс | `http://127.0.0.1:8000/` |
| Desktop-клиент | PyQt6, собирается в `CompetitionMonitor.exe` |

### Поля под нишу

| Поле | Диапазон | Смысл |
|---|---|---|
| `design_score` | 0–10 | визуальный стиль: типографика, цвет, композиция |
| `trust_score` | 0–10 | элементы доверия: реквизиты, лицензии и членство, кейсы, отзывы |
| `pricing_transparency` | 0–10 | понятны ли цены, сроки, состав работ |
| `tariff_expertise_depth` | 0–10 | глубина экспертизы по тарифам: методы, регуляторы, кейсы, суды (аналог `animation_potential` из учебного примера) |
| `service_coverage` | флаги | есть ли у конкурента финансовое сопровождение, аудит, тарифы |

Оценки приводятся к диапазону 0–10 на стороне сервера, даже если модель вернула 11 или строку.

## Быстрый старт

Нужны Python 3.11+, Google Chrome и ключ OpenAI (или ProxyAPI).

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt

copy .env.example .env     # и впишите ключ в .env
uvicorn run:app --reload
```

Откройте <http://127.0.0.1:8000/>. Интерактивная документация API: <http://127.0.0.1:8000/docs>.

Драйвер Chrome Selenium скачивает сам (Selenium Manager).

### Настройки (файл `.env`)

| Переменная | Значение по умолчанию |
|---|---|
| `OPENAI_API_KEY` | пусто (обязательно) |
| `OPENAI_BASE_URL` | пусто; для ProxyAPI: `https://api.proxyapi.ru/openai/v1` |
| `OPENAI_MODEL` | `gpt-4o-mini` |
| `OPENAI_VISION_MODEL` | `gpt-4o-mini` |

Конкуренты и их адреса: список `COMPETITORS` в `backend/config.py`.

## Данные конкурентов и массовый прогон

```bash
python collect.py collect    # Selenium: скриншот и текст каждой страницы -> data/
python collect.py analyze    # (сервер запущен) разбор всех материалов -> results/ и results/summary.md
```

Папки `data/` и `results/` в репозиторий не попадают: это чужие материалы и результаты анализа реальных компаний.

## Desktop-приложение

```bash
pip install -r desktop/requirements.txt
cd desktop
python main.py          # запуск из исходников
python build.py         # сборка dist/CompetitionMonitor.exe
```

`CompetitionMonitor.exe` это клиент: сервер (`python run.py`) запускается отдельно. Адрес сервера можно поменять переменной `COMPETITOR_API`. Антивирус иногда ругается на `.exe`, собранный PyInstaller, это ложное срабатывание; при сомнениях запускайте из исходников.

## Тесты

```bash
pip install -r requirements-dev.txt
pytest
```

28 проверок без сети и без ключа: модель и браузер подменены. Покрыто: форма ответов, ограничение оценок, JSON в блоке кода, ответ модели без JSON, отсутствующий ключ, проверка загружаемых файлов, обработка ошибок парсинга, история на 10 записей, защита от обращения к локальной сети (в том числе адреса NAT64).

```

```

## Безопасность

- Ключ хранится только в `.env`; файл внесён в `.gitignore`, в репозиторий не попадает. В репозитории лежит `.env.example` без значений.
- `/parse_demo` принимает только публичные адреса `http/https`: локальная сеть и служебные адреса блокируются.
- Ответ модели в интерфейсе выводится как текст, не как разметка.
- Загрузки изображений проверяются: формат, размер до 8 МБ; большие картинки уменьшаются.

## Ограничения

- Анализ делает языковая модель по открытым страницам: это материал для размышления, а не факт. Цифры, цены и реквизиты проверяйте по источнику.
- Сайты могут блокировать автоматический сбор; тогда `/parse_demo` вернёт понятную ошибку.
- Перед сбором данных проверяйте условия использования сайта.
